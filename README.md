# VOID / STUDIO

React + Vite portfolio starter for an AI designer.

## Local preview

```bash
npm install
npm run dev
```

Then open the local URL printed by Vite.

## Replace content

- Images, videos, titles, and descriptions live in `src/data/portfolio.js`.
- The main section components live in `src/App.jsx`.
- Global layout, responsive rules, and visual tokens live in `src/styles.css`.
- Reference images supplied during the brief are copied into `public/assets/` as stable local hero, composition, and contact placeholders.
